คำแนะนำการขึ้นระบบบน GitHub Pages

ขั้นตอนการนำไฟล์นี้ไปแสดงผลบน Web App (GitHub Pages):

  1. บันทึกซอร์สโค้ดนี้ตั้งชื่อไฟล์ว่า index.html
  2. สร้าง Repository ใหม่ใน GitHub (เช่น public-health-dashboard)
  3. Upload หรือ Commit ไฟล์ index.html ขึ้นสู่รากหลัก (main/master branch)
  4. ไปที่ **Settings** ของ Repository -> เมนู **Pages** ด้านซ้ายมือ
  5. ตรง **Source** เลือก Deploy from a branch และเลือก branch main แล้วกด Save
  6. ภายใน 1-2 นาที คุณจะได้ URL เว็บไซต์สำหรับเปิดใช้งานจริงทันที!
**เคล็ดลับสำหรับ Google Sheets:** ให้ไปที่ Google Sheets ของคุณ -> เลือก **File > Share > Publish to Web** -> เลือกแท็บ หรือส่งออกเป็น **CSV** แล้วนำลิงก์แปะที่ช่อง Google Sheets URL ในหน้าแดชบอร์ด ข้อมูลจะอัปเดตตรงทันทีแบบ Realtime!
